# Persistent setup and removal

Normal temporary tests restore their DLLs when the game exits. Their launch environment belongs to the process started by the tester; Steam does not inherit those values on a later launch. This explains why a temporary test does not automatically configure later Steam launches.

**Keep framegen setup installed** is opt-in and off by default. It works with compatible x64 game executables from Steam or other folders, without requiring a Steam library manifest or App ID. Select the game and current DLL option, then enable the toggle. Installation uses the same durable backup journal as normal tests. The selected option stays installed until explicitly disabled; the app may be closed.

For an NVSmooth30 option, the persistent files are:

- The selected supported proxy name, containing the bundled official Ultimate ASI Loader.
- A matching proxy INI configured to load only the named helper.
- `FramegenLab.Steam.asi`, an original small native configuration helper generated by this tester.
- `FramegenLab.SteamBackend.dll`, the selected hash-verified NVSmooth30 image, copied without modifying its bytes.

The helper's DllMain only returns TRUE. Ultimate ASI Loader calls its exported InitializeASI outside its DllMain with DontLoadFromDllMain=1. The helper sets the same SM86 process-local profile values used by Start game, then uses ordinary Windows LoadLibraryW on the exact backend path. It does not write global environment variables, change Steam launch options or alter protection settings. Its original emitter source is [SteamBootstrap.cs](../src/SteamBootstrap.cs); no third-party DLL is decompiled or recompiled for this feature.

DLSSG options retain their existing proxy DLL and matching INI; they do not require the NVSmooth30 environment helper.

While enabled, **Open game** uses the normal Steam URL for recognized Steam installations and starts the selected executable with its game folder as working directory otherwise. The game's usual launcher can also be used outside the tester; its own login, ownership and arguments still apply. File installation alone does not prove a game imports the chosen proxy or that frame generation works. The generated helper and a non-Steam direct-launch fixture were verified in disposable processes; live frame generation still needs a game test. Normal anti-cheat restrictions apply.

**Toggle OFF**, **Remove test DLL**, **Stop + restore** and **Reset tests** all restore tracked originals and remove every newly installed tracked helper. Existing original files are restored instead of erased. Game / mod logs created during use are retained, as are backups and history. Other game DLLs are outside this operation.

Changing DirectX also removes the persistent setup before changing the sequence. Reopening the app verifies installed file hashes; changed or missing files require restoration rather than claiming the setup is enabled.
